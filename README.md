# Wayfarer's Ledger

A browser-first, independently authored prototype about travel, a small crew, turn-based encounters and trading.

## Play

Open the playable prototype at /game/. The game saves locally in the current browser. It has no account, backend or external runtime dependencies.

## Local run

From the repository root, start any static HTTP server and open /game/. For example:

    python3 -m http.server 8000

Then open http://localhost:8000/game/.
